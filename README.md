# Website Pessoal

Website pessoal desenvolvido como atividade acadêmica durante o primeiro semestre de 2025, no primeiro período do curso de Ciência da Computação, utilizando HTML5 e CSS3.

## Sobre o projeto

O site foi desenvolvido para apresentar informações pessoais, trajetória acadêmica, projetos e interesses profissionais. Durante o desenvolvimento, foram utilizados conhecimentos de HTML e CSS para criar as páginas e organizar a navegação entre elas.

## Páginas

O site possui cinco páginas:

- **Home:** apresentação pessoal.
- **Sobre mim:** informações pessoais e formação acadêmica.
- **Meus projetos:** apresentação de projetos desenvolvidos.
- **Novidades:** interesses na área de tecnologia e objetivos profissionais.
- **Contato:** formulário de contato e links para redes sociais.

## Tecnologias utilizadas

- HTML5
- CSS3

## Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.

## Observações

Foram desenvolvidos dois arquivos CSS com diferentes disposições do menu de navegação. A versão utilizada atualmente é a "stylevertical.css".

O formulário de contato possui apenas a interface em HTML, sem integração com um backend para o envio das mensagens.
